The AI-Ready Language
Built for Simplicity & Speed

Cruise is a lightweight programming language featuring human-readable syntax, native PyTorch tensor calculus, built-in machine learning predictors, and instant desktop GUI controls.

$ pip install cruise-lang
Try Code Examples Star on GitHub

Why Developers Love Cruise

Engineered from the ground up to combine plain-English readability with powerful deep learning backend tools.

Plain-English Syntax

Intuitive keyword commands like let [var] be [val], write(), ask(), and times make code read like natural thought.

PyTorch Autograd

Native support for multi-dimensional tensor arrays with built-in automatic differentiation derivatives (compute_gradients).

Built-in ML Predictor

Execute machine learning model predictions directly inside scripts using built-in pre-trained predictors like predict("house_prices", val).

Zero-Config GUI Apps

Build instant desktop visual application windows and event-driven buttons with single lines of Cruise code (background, button).

Dual Execution Modes

Run interactively line-by-line via the REPL terminal shell, or execute standalone script files saved with .cru or .cruise extensions.

Memory & File Logs

Store long-term variable snapshots in an in-memory session timeline log (remember) or append data straight to disk files (log).

Code Examples

See how clean and readable Cruise scripts look in action.

app.cru
Cruise Engine v0.1.1 
# 1. Ask for developer name & print greeting
let developer be ask("Enter developer name:")
write("Welcome aboard, " + developer + "!")

# 2. Easy One-Line Automation Loop
3 times write("Cruising fast! 🚀")

# 3. Dynamic Conditional Logic
let test_val be 42
if test_val > 40 then write("Condition passed successfully!")

# Tensor Calculus powered natively by PyTorch
let x be array([2.0, 4.0, 6.0])
let y be x * x + 5

write("Calculated Tensor values (x^2 + 5):")
write(y)

# Perform backward pass and output derivatives
compute_gradients(y)
write("Calculated Autograd Gradients:")
write_gradient(x)

# Real-time regression predictions with built-in ML models
let house_size be 5
let predicted_price be predict("house_prices", house_size)

write("Estimated Price Output:")
write(predicted_price)

# Log prediction snapshot to session memory & file
remember(predicted_price)
log("predictions.log", predicted_price)

# Create Desktop UI Window & Interactive Buttons
background("lightblue")

# Add functional buttons with custom colors
button("Sound Alert", beep(), "lightgreen")
button("Log Score", remember(100), "yellow")

Language Quick Reference

Complete cheat sheet of standard commands supported by the Cruise engine.

Feature Cruise Syntax Command Description
Variables let x be 100 Assigns integer, decimal, or text string value to a variable.
Print Output write("Hello " + name) Prints expressions, text, or variable values to standard output console.
Console Input let val be ask("Prompt:") Interactively asks the user for terminal keyboard input.
Automation Loops 3 times write("Hi") Repeats the given command N times in a single line.
Conditionals if x > 10 then write("Pass") Evaluates logical expression and executes action command if true.
Tensors (PyTorch) let t be array([1.0, 2.0]) Creates a PyTorch tensor matrix with Autograd derivative tracking.
Autograd Derivatives compute_gradients(y) Executes backward pass autograd calculus solver.
ML Predictions predict("house_prices", 5) Runs pre-trained regression models to forecast outputs.
Desktop UI Window background("blue") Initializes visual Tkinter desktop app window with background color.
Interactive Button button("Click", beep(), "green") Creates a clickable UI button linked to a Cruise action.
